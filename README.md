# سينما — مشغل أفلام محلي

مشغل أفلام عربي مبني بـ Next.js وTailwind CSS. يقرأ الأفلام من مجلد `assets` تلقائيًا، ويدعم اختيار الملفات مباشرة من الجهاز.

## التشغيل

```bash
pnpm dev
```

ثم افتح `http://localhost:3000`.

## إضافة فيلم

ضع ملفات الفيديو في `public/assets/videos`. لفيلم بجودة واحدة استخدم مثلًا `My Movie.mp4`.

لإظهار قائمة اختيار الجودة، استخدم الاسم نفسه مع لاحقة الجودة:

```text
public/assets/videos/My Movie-1080p.mp4
public/assets/videos/My Movie-720p.mp4
public/assets/videos/My Movie-480p.mp4
```

## الترجمة والملصق

ضع الترجمة بصيغة SRT أو VTT في `public/assets/subtitles`، ويجب أن يبدأ اسمها باسم الفيلم:

```text
public/assets/subtitles/My Movie.ar.srt
public/assets/subtitles/My Movie.en.vtt
```

اللغات المعروفة في الاسم: `ar` و`en` و`fr` و`es` و`tr`.

يمكن إضافة صورة ملصق في `public/assets/posters` باسم الفيلم، مثل `My Movie.jpg`. بعد إضافة الملفات حدّث الصفحة، وسيظهر الفيلم في المكتبة.

## التحكم

- تشغيل وإيقاف، تقديم وتأخير 10 ثوانٍ، مستوى الصوت والكتم.
- تغيير الجودة مع الحفاظ على موضع التشغيل، وسرعات من 0.5× إلى 2×.
- تكبير الصورة حتى 160% مع وضعي الاحتواء وملء الإطار.
- شاشة كاملة، وصورة داخل صورة، وتنزيل الملف.
- تشغيل وإيقاف الترجمة واختيار اللغة.
- تخصيص حجم ولون وسمك وموقع وخلفية وظل الترجمة.
- حفظ موضع المشاهدة وإعداد الترجمة داخل المتصفح.

اختصارات لوحة المفاتيح: `Space` أو `K` للتشغيل، `J` و`L` أو الأسهم للرجوع والتقديم، `M` للكتم، `F` للشاشة الكاملة، و`C` للترجمة.
